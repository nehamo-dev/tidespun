# tidespun
Production platform for AI native creators

## Website
Marketing homepage for Tidespun, the end-to-end publishing platform for AI-native creators.

## What's here
- `index.html`: the full homepage (responsive, desktop and mobile)
- `assets/`: logo and artwork files

## Run locally
Open `index.html` in a browser, or serve the folder with any static server, for example:

```
python3 -m http.server 8000
```

## Deploy
This is a static site with no build step. It can be hosted as-is on GitHub Pages, Netlify, Vercel or Cloudflare Pages.
